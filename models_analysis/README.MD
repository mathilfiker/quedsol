# Analysis

This directory contains the scripts to reproduce the analyses reported in the publication.

## Content of the directory

- evaluation_scripts: contains scripts to evaluate the trained Allegro, MACE, and MACEDipole models.
- out_of_equilibrium: contains scripts to print the errors on the predictions for molecules out of equilibrium
- scalability: contains scripts to print the errors on the scalability analysis
- transferability: contains scripts to print the errors on the transferability analysis
- ahfe_predictions: contains the scripts to train a QUEDSol model on FreeSolv and test it on FlexiSol
